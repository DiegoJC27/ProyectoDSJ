Wacky Asteroids 2

Wacky Asteroids 2 es un juego tipo arcade en el que tu objetivo es 
destruir la mayor cantidad de asteroides posibles antes que te 
destruyan a ti.

Esta hecho con raylib v6.1, la versión más actual de la librería raylib.
Así mismo, implementa librarias adiciones, siendo raygui v5.0, para el 
diseño de interfaces, y json de nlohmann, que es un alibreria para leer 
y editar archivos json que uso para guardar el highscore entre partidas.

Controles:
W,A,S,D: Moviiento vertical y horizontal.
Espacio: Disparar.
